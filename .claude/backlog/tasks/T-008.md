## Yapılanlar
- **Parite analizi:** `docs/analysis/0001-kpi-parity-analysis.md` (sapmalar + BRD ihlalleri + test matrisi).
- **KPI config BRD'ye getirildi:** `kpi.service.seedDefaults` + yeni `kpi.seed.ts` (idempotent upsert); engine tek doğruluk kaynağı.
  - `GP_ROI_PCT = INCR_GP / INCR_SPEND * 100` (eski yanlış: GP/TACTIC_SPEND).
  - `INCR_GP = PLANNED_GP - BASE_GP`.
  - `PLANNED_TO = PLANNED_GSV - PLANNED_ON_INVOICE_SPEND`, `BASE_TO = BASE_GSV - BASE_LTA_ON` (NIV: yalnızca on-invoice kesinti turnover'ı düşürür — off-invoice düşürmez).
- **Context'e SpendCalc enjeksiyonu:** PLANNED_LTA_ON/OFF, PLANNED_ON_INVOICE_SPEND, TOTAL/INCR_SPEND.
- **plan.service'teki TÜM hardcoded fallback + RAG `<15` kaldırıldı**; eksikte null; hata yüzeye (sessiz yanlış değer yok). `getAnalysis` da saklı KPI'ları okur (recompute/hardcoded targetRoi yok).
