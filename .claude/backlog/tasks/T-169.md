## ⛔ İkinci yarı cevaplandı: **iki faz iç içe girmiş** ([[T-143]] turu 28 / `0046`)

Phase 2'nin **yarısı** var:

| var | yok |
|---|---|
| grid · hacim girişi · FU tactic · Grand Totals | **What-if analysis (0 dosya)** |
| KPI motoru çekirdeği · aggregation · edge case | 40+ KPI yerine **27** |
| RAG · COMMIT · baseline **import ekranı** | baseline **validation + ≥%95 zorlaması** |
| Plan Performance Report | **Planner Performance · ROI Distribution** |
| — | **ROI-based approval policies · auto-reject** |

### 🔴 En çarpıcı: Phase 2'nin **varlık sebebi** eksik

Tagline: *"Plan with intelligence, **approve with confidence**"*
Value prop: *"Category Managers can **simulate ROI** before committing budget"* ·
*"10-15% higher ROI through **what-if optimization**"*

**`whatIf|what-if|simulat` → frontend'de 0 dosya.**

> **Altyapı inşa edilmiş, değer önerisi inşa edilmemiş.** Ve Phase 2'nin başarı ölçütü
> *"ROI optimization: 10%+ improvement (draft → final)"* what-if olmadan **ölçülemez bile**.

### Sıralama sonucu — bağımlılık ölçümü

| Phase 2 eksiği | bağlı olduğu Phase 1 eksiği |
|---|---|
| ROI-based approval policies · auto-reject | **`approval_policies`** ([[T-153]]) |
| baseline ≥%95 zorlaması | baseline sahibi + kapsama ([[T-024]]) |

> **"Önce Phase 1 tabanı" seçeneği, Phase 2'nin eksik yarısının da ön koşulu.**
> İki iş sıralı değil — **birincisi ikincisinin altında**.

⚠️ Bu bir **bağımlılık ölçümü**, öneri değil. Karar ürün sahibinin.
