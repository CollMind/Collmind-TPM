## Açıklama — BRD'nin finans panosu bugün **kullanılamaz**

Playwright ile ölçüldü (`docs/analysis/0058` D1): `/finance` React hatasıyla çöküyor —
*"Rendered more hooks than during the previous render"*.

**Kök neden ölçüldü:**

```
SpendCompositionWidget.tsx:36   return <LoadingSpinner />;    ← erken çıkış
SpendCompositionWidget.tsx:72   const [selectedSlice, setSelectedSlice] = useState(...)  ← SONRA hook
```

`isLoading` `true → false` döndüğünde React bir önceki render'dan **fazla hook** görüyor.

**İkinci kusur, aynı ekranda:** `finance-reporting.endpoints.ts` backend DTO'sunun
reddettiği query parametreleri gönderiyor (`granularity` · `comparisonType` · `months` ·
`startDate` · `endDate`) → `forbidNonWhitelisted` → **6× 400**.

> Yani ekran hem **çöküyor** hem de altındaki altı istek **reddediliyor**. İkisi ayrı
> kusur; biri düzeltilse diğeri kalır.

## ⛔ Ve asıl ders: **ESLint bunu zaten biliyordu**

```
npx eslint src/components/finance/widgets/SpendCompositionWidget.tsx
→ 72:45 error  React Hook "useState" is called conditionally … Did you accidentally
               call a React Hook after an early return?     react-hooks/rules-of-hooks
```

Kural **var**, **doğru**, ve **tam bu satırı** gösteriyor. Ama frontend'de
`npm run lint` **repo genelinde kırmızı** ([[T-114]]) — yani bu hata 470+ başka bulgunun
içinde kayboluyor.

> `CLAUDE.md §2.7 #9`: ***"Sinyal sabitse, sinyal değildir."***
> Bu, o maddenin **ölçülmüş bedeli**: bir kapı hep kırmızı olduğu için, çöken bir ekranı
> haber veren gerçek bir hata **fark edilmedi**.

⚠️ [[T-114]] bir ratchet kurmuştu (taban 488/112). Bu vaka onun **önceliğini yükseltiyor**:
ratchet yeni hataları durdurur, ama **mevcut kırmızının içindeki** bu hata zaten oradaydı.

## Yapılacak

1. `useState`'i erken `return`'ün **üstüne** taşı (ya da erken çıkışı kaldır).
2. Query parametrelerini backend DTO'suyla **hizala** — hangisi doğru? DTO'yu **oku**,
   frontend'i ona uydur; DTO eksikse **bildir** (bu bir sözleşme kararı olabilir).
3. **Say (`§7.1`):** `react-hooks/rules-of-hooks` **başka** kaç dosyada tetikleniyor?
   Her biri potansiyel bir çökme. Cevap bir **komut çıktısı** olsun.
4. `/finance` Playwright ile **açılıyor** ve konsol hatası **yok** — kanıtla.
