## ⭐ ÖNCE — `23P01` sınıfının **ÜÇÜNCÜ ÜRETİCİSİ** sarmalanmamış (`🟡-1`, reprodüksiyonla ölçüldü)

`wrapPeriodRangeConflict` `createEnvelope`'un **iki** çağrı yerinde. Ama trigger yalnız
`INSERT`'te değil:
```
BEFORE INSERT OR UPDATE OF period_from, period_to, category, channel, spend_type, tenant_id, deleted_at
```
`budget.service.ts:2119` — `splitEnvelope` adım 6, `spendType`'ı `ON_INVOICE`'a çevirip
`updateEnvelope` çağırıyor. Review canlı DB'de (`BEGIN`/`ROLLBACK`) **üretti**:
```
INSERT spend_type=NULL       2026-01..2026-01   → OK
INSERT spend_type=ON_INVOICE 2026-01..2026-01   → OK   (tuple FARKLI)
UPDATE SET spend_type='ON_INVOICE' WHERE code='RV-UNTYPED'
   → ERROR 23P01: overlaps existing envelope RV-ON
```
⇒ `POST /budget/envelopes/:id/split` → **yakalanmamış `23P01`** → **`500`**.
⛔ `DISIPLIN`: *"bir AD, koruduğu SINIFTAN dar olabilir"* — sarmalayıcının adı
`createEnvelope`'a değil, **`23P01` SINIFINA** bakmalı.

## `🟡-2` — aynı iki çağrı yeri **`23514`** de üretiyor → yine `500`
`period` DTO'da **format doğrulaması YOK** (`@IsString @MinLength(1) @MaxLength(50)`), ve
entity yorumu **açıkça** `"Jan"`, `"Q1"`, `"2024"` örnekleri veriyor. `periodFrom = periodFrom ?? period`
⇒ `period='Q1'` → `CHK_..._PERIOD_FROM_FORMAT` ihlali → `23514` → çeviriciden **geçmez** → `500`.
⇒ **DTO'ya göre GEÇERLİ** bir gövde `500` üretiyor. `fiscalYear` (`MaxLength(10)`, ör. `'2026-27'`)
aynı sınıf. ⇒ DTO'da `@Matches(/^\d{4}-(0[1-9]|1[0-2])$/)` **ya da** türetimden önce açık `400`.
