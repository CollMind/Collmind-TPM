## Açıklama
T-029 sırasında bulundu: BRD plan state machine'i
`Draft → Pending Approval → Approved/Rejected; **Rejected → Draft** (audit korunur)` diyor.
Kodda **Rejected→Draft geçişi için hiçbir endpoint/servis yolu yok**. Yalnızca
`ApprovalWorkflowService.requestChanges` var ve o `Pending → Draft` yapıyor (farklı geçiş).

Sonuç: reddedilen bir plan ölü kalıyor — planner düzeltip yeniden gönderemiyor.

## Acceptance Criteria
- [ ] `Rejected → Draft` geçişi (endpoint + servis), yalnızca plan sahibi/PLANNER + ADMIN
- [ ] Audit korunur: geçmiş history kayıtları silinmez, yeni bir history satırı eklenir
- [ ] Bütçe tutarlılığı: reject'te RELEASE edilmişti; Draft'a dönüşte rezerv **kurulmaz**
      (yeniden submit'te kurulur) — T-029 reserve/commit semantiğiyle tutarlı
- [ ] Yeniden submit edilebildiği e2e ile kanıtlanır (reject → draft → submit → approve)
- [ ] Unit + e2e yeşil
