Senaryolar (her biri **yalnız UI'ın doğrulayabileceği** şeye odaklı; backend'in 209 e2e'si
tekrarlanmadı):
1. `01-login-rbac` — rol bazlı sidebar. Backend guard'ları "yetkisiz aksiyon reddedilir" der;
   UI'ın o aksiyonu **hiç sunmadığını** kanıtlamaz.
2. `02-version-conflict` — 409 `STALE_VERSION` diyaloğu + **otomatik yeniden gönderim YOK**
   ([[T-034f]]'in en kritik güvencesi). Backend 409 döndüğünü kanıtlar; tarayıcının o 409'u
   sessizce retry etmediğini kanıtlayamaz.
3. `03-file-upload` — multipart FormData. [[T-040]]'ta bulunan gerçek `Content-Type` boundary
   hatasının sınıfı; backend e2e frontend axios client'ını hiç çalıştırmaz, unit testler mock'lar.
4. `04-grid-cell-kpi` — hücre düzenleme → KPI kartı. Backend API doğruluğunu kanıtlar; grid'in o
   query'e abone olduğunu kanıtlamaz.
