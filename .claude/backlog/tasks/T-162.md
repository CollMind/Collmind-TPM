## Bulgu ([[T-143]] turu 12 / `docs/analysis/0030 §3` ve `§4`)

### 1. RAG toplama kuralı — normatif, kodda karşılığı ölçülmedi

`Section_05 §5.2` (ve Glossary, birebir aynı):

```
If any SKU is Red        → FU is Red
If no Red but any Amber  → FU is Amber
If all Green             → FU is Green
```

*"En kötü kazanır."* **Plan seviyesinde** de aynı mı — ölçülmedi.

### 2. Negatif ROI: *"flag for review"* — ölçülmedi

`§5.3 Edge Case Handling`: negatif ROI **geçerlidir**, ve UI davranışı
*"Display in red, **flag for review**"*.

Bizde kırmızı gösterim var (RAG `< %10`, negatif de o kovada). Ama **"inceleme işareti"**
ayrı bir şey mi — onay akışında bir sinyal mi, yoksa yalnız görsel mi? Ölçülmedi.

⚠️ İlgili: Glossary `Approval Policy` maddesi *"Auto-Reject: If GP ROI <5%"* diye bir örnek
veriyor. Yani ROI'nin onay akışına **girdiği** bir tasarım var ve bizde
[[T-153]] (politika katmanı yok) yüzünden yeri belirsiz.
