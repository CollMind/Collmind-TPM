## Kusur

`effect_data_wide` (tek `awk … > "$2"`), `effect_snapshot`, `strip_data_section`/`extract_data_section` ve
`cp … DATA_WIDE_*` çağrılarının **rc'si okunmuyor**.

```
[ÖLÇÜLDÜ: migration-verify.sh okundu, 2026-09-13]
k1_tespit_var: strip_data_section A/B → diff -q ndA ndB → diff -q wideA wideB
yazma hatası (ör. WORKDIR dolu) ⇒ dört dosya da BOŞ ⇒ iki diff de "eşit" ⇒ return 0 = "tespit VAR"
  beyanlı DATA_VOLATILE_INSERT  → YEŞİL + "veri-kolu ÖLÇEMEDİM" satırı    ⛔ SAHTE YEŞİL YÖNÜ
  beyansız                      → exit 2 ÖLÇEMEDİM                        (yanlış sebepli)
```

⛔ **Yön notu (`Z111 §28.1 N36`):** bu kusur ilk kayıtta *"kırmızı yönlü, güvenli"* diye sınıflandı; kod okunduğunda
beyanlı yolda **yeşil** yönlü olduğu görüldü. Erişilebilirlik düşük (aynı yazma hatası önceki snapshot'ları da büyük
olasılıkla ÖLÇEMEDİM'e düşürür) — ama **ölçülmedi**.

`Z111 §26` R1 ile aynı aile (*"değer boşken eşitlik, varlığın kanıtı değildir"*) — orada `$( )` alt kabuğu, burada
**rc hiç okunmuyor**.
