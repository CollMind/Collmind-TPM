## Açıklama
T-020 backend'i tamamladı (5 endpoint), frontend karşılığı yok. Kullanıcı actuals CSV'sini
UI'dan yükleyebilmeli, batch geçmişini ve reddedilen satır hatalarını görebilmeli.

Backend sözleşmesi:
```
POST /actuals-first/sales-actuals/upload?fiscalPeriod=YYYY-MM  (multipart; ADMIN/FINANCE/FINANCE_MANAGER)
GET  /actuals-first/sales-actuals/batches?fiscalPeriod=&status=
GET  /actuals-first/sales-actuals/batches/:batchId
GET  /actuals-first/sales-actuals/batches/:batchId/rows
GET  /actuals-first/sales-actuals/summary?fiscalPeriod=&cplId=&categoryId=&channelId=
```
Silme endpoint'i YOK (immutable) — UI'da silme aksiyonu gösterme.

## Acceptance Criteria
- [ ] Upload ekranı (dosya seç + dönem; dönem boşsa dosya adından çıkarım bilgisi)
- [ ] Sonuç: kabul edilen satır/batch özeti + reddedilenler hata koduyla (UNKNOWN_CPL,
      UNKNOWN_CATEGORY, AMBIGUOUS_CATEGORY, CHANNEL_MISMATCH, NET_EXCEEDS_GROSS…) + warning'ler
- [ ] Batch geçmişi: ACTIVE/REPLACED rozetleri, replacement zinciri (replacedByBatchId) görünür
- [ ] RBAC: yalnızca ADMIN/FINANCE/FINANCE_MANAGER upload görür; diğerleri salt okuma
- [ ] Mevcut on-invoice upload ekranı pattern'i reuse (yeni pattern getirme)
