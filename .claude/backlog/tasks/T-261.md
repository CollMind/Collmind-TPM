## Bulgu — `T-258` turunda ölçüldü

```
docker ps    collmind-tpm-backend   Up · 0.0.0.0:3000->3000/tcp
docker inspect                      7 restart · running
curl localhost:3000/auth/login      HTTP 000  (bağlantı yok)
```

Alt-ajanın raporu: container `ENOTFOUND postgres` ile çöküyor, ve konfigürasyonu bu
reponun ortamıyla **uyuşmuyor** — şema `public`, port `5433`.

⚠️ **`CLAUDE.md`'nin doğrulanmış ortam notlarıyla çelişiyor:**

```
CLAUDE.md    DB portu 5434 · şema main · container collmind-tpm-postgres
container    port 5433     · şema public · host "postgres" (çözülemiyor)
```

container'ın durumuna bağlı. E2e **etkilenmiyor** (kendi app'ini kuruyor) — ayrım
önemli.
