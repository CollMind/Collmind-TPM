## Açıklama

`MechanicService#update` (`mechanic.service.ts:181-190`):

```ts
const minValue = updateMechanicDto.minValue ?? mechanic.minValue;
const maxValue = updateMechanicDto.maxValue ?? mechanic.maxValue;
if (minValue !== undefined && maxValue !== undefined && minValue >= maxValue) {
  throw new BadRequestException('minValue must be less than maxValue');
}
```

DB'den gelen değer `null`'dır, `undefined` değil. `null !== undefined` **true**, yani koruma
devreye girer. Ardından JS karşılaştırması sayısal coercion yapar: `0 >= null` → `0 >= 0` →
**true** → sahte 400.

Sonuç: `minValue` veya `maxValue`'dan biri `null` olan **her** mekanik,
`PATCH /master-data/mechanics/:id` üzerinden **herhangi bir alan** güncellemesinde (yalnızca
`isActive` göndersen bile) 400 alıyor.

## Beklenen davranış

Yalnız **her ikisi de tanımlıyken** ve `minValue >= maxValue` iken reddet.

`null` ve `undefined` ayrımı burada anlamsız — ikisi de "sınır yok" demek. Kontrol
`!= null` (gevşek eşitlik, ikisini birden yakalar) veya açık `Number.isFinite` ile yapılmalı.

⚠️ **Karşılaştırmadan önce tip:** `min_value`/`max_value` `numeric` kolonlar ve TypeORM
bunları **string** döndürebilir. `'0' >= '100'` string karşılaştırmasıdır ve `true` verir.
Düzeltme bunu da kapsamalı — yoksa kusur şeklini değiştirip kalır.
