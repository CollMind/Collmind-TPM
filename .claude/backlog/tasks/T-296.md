`T-294` `months` için **tel-protokol kopukluğunu** kapattı. `code-reviewer` sordu:

## Ölçüldü (gerçek HTTP, ADMIN token, izole worktree)

```
GET /finance-reporting/spend-trend?granularity=monthly
  → 400 ["property granularity should not exist"]
GET /finance-reporting/spend-trend                      (parametresiz)
  → 200                     ← POZ.KONTROL: uç sağlam, kıran şey PARAMETRE
GET /finance-reporting/variance-analysis?comparisonType=budget_vs_actual
  → 400 ["property comparisonType should not exist"]
```

**DTO'da yoklar** (poz.kontrol: `months` taşındıktan sonra `2` eşleşme veriyor):
```
granularity     ReportFilters'ta 0 eşleşme
comparisonType  ReportFilters'ta 0 eşleşme
```

**Ve frontend ikisini de HER İSTEKTE gönderiyor** (varsayılanları var, hiç atlanmıyor):
```
finance-reporting.endpoints.ts  getSpendTrend(filters, granularity = 'monthly')
                                  → params: { ...filters, granularity }
                                getVarianceAnalysis(filters, comparisonType = 'budget_vs_actual')
                                  → params: { ...filters, comparisonType }
çağıranlar: FinanceDashboard · SpendTrendWidget · VarianceAnalysisWidget
```

⇒ **Finance Dashboard'da iki widget daha, herkes için `400`.**

## ⚠️ Ama sınıfı `months`'unkinden DAR — ve sebebi ölçüldü

`granularity`/`comparisonType` **TS enum/union** tipli; `design:paramtypes` `Object`
emit ediyor, `ValidationPipe`'ın `metatype === Number` dalına **girmiyor** → değer
`undefined` kalıyor → JS varsayılanı **devreye giriyor**.

```
months                400  +  NaN → RangeError → 500  +  (potansiyel sessiz yanlış değer)
granularity/comparisonType   400  (yalnız)
```

⇒ Sessiz yanlış değer **yok**. Ama `400` **canlı**.

## Düzeltme şekli — `§7`'nin cevabı REPODA ZATEN VAR

`code-reviewer` mevcut deseni buldu: **`BudgetVarianceQueryDto`**
(`budget-variance-report.dto.ts`), **aynı controller'da** `@Query()` olarak
kullanılıyor. Yani uç-özel query DTO'su bu dosyada **zaten var** ve aranmamıştı.

```
class SpendTrendQueryDto      extends ReportFilters { granularity }
class VarianceAnalysisQueryDto extends ReportFilters { comparisonType }
class CashFlowProjectionQueryDto extends ReportFilters { months }   ← T-294'ü de düzeltir
```

⚠️ **Üçüncüsü `T-294`'ün `S2` bulgusunu kapatır:** `months` bugün **paylaşılan**
`ReportFilters`'ta ve o DTO **sekiz uçta** kullanılıyor ⇒ sekiz ucun hepsi
`?months=6`'yı **kabul edip sessizce yok sayıyor**, ve `?months=0` için
**anlamsız yere `400`** veriyor.
