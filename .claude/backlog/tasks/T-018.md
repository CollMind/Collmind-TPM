## Açıklama
T-017 tespit etti: SpendCalc tactic sınıflandırmasını `Mechanic.spendingType`/`category`/
`mechanicType`'tan okur. Ama seed'de yalnızca `MEC-DISCOUNT` var; gerçek planlama
mechanic'leri (CPP_ON_PCT, VIS_LS, PRICE_SUP, DISPLAY_FEE vb.) seed'de yok — Admin UI ile
yaratılıyor. Bu alanlar null kalırsa SpendCalc 0 spend hesaplar → yanlış on/off bütçe rezervasyonu.

- [ ] Standart planlama mechanic'leri için master-data seed (`mechanic.seed.ts`): kod, spendingType, category, mechanicType, formül — BRD/Wella mekaniklerine göre

- [ ] seed/index + cleanup-and-seed entegrasyonu
- [ ] SpendCalc delegasyonu seed veri üzerinde doğru on/off üretir (e2e)
