## ⛔ BU TASK BİR ROL KARARI DEĞİL

Kusur **ayrışmada**: ekran kapısı ile rota kümesi **aynı fikirde değil**. İki
düzeltme yönü var ve **hangisi doğru olduğu ürün sahibi kararıdır**:

```
(i)  rota kümesini ekrana hizala    → rol GENİŞLETMESİ, kayıtlı istisna ister
(ii) ekranı/widget'ı rota kümesine  → UI'da rol kapısı, davranış korunur
```

⇒ **Karar gelmeden düzeltme yapılmaz.** Bu task kusuru **kaydeder ve ölçer**.
