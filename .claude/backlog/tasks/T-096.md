## Kusur 1 — `created_by` iki kez map'li → her INSERT `42701`

`budget-transaction-log.entity.ts:59`:
```ts
@Column({ name: 'created_by', type: 'uuid', nullable: true })
createdById?: string;
```

`base.entity.ts:27` **aynı kolonu** zaten map'liyor:
```ts
@Column({ name: 'created_by', type: 'uuid', nullable: true })
createdBy?: string;
```

İki property → tek kolon → TypeORM INSERT'te `created_by`'ı **iki kez** yazıyor:

```
ERROR: column "created_by" specified more than once (42701)
```

**Entity dizinindeki tek böyle vaka** — diğer entity'lerde `createdById` yok.

`reserveBudget` · `commitBudget` · `releaseBudget` · `createAllocation` — hepsi
