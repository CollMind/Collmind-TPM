## ⚠️ Bu, oturumun en ciddi bulgusu — para diske yanlış yazılıyor

`budget-allocation.service.ts:421-424`:

```ts
allocation.onInvoiceReserved  -= reservation.onInvoiceAmount;   // ← DOĞRU çalışıyor
allocation.onInvoiceUtilized  += reservation.onInvoiceAmount;   // ← BİRLEŞTİRİYOR
allocation.offInvoiceReserved -= reservation.offInvoiceAmount;  // ← DOĞRU
allocation.offInvoiceUtilized += reservation.offInvoiceAmount;  // ← BİRLEŞTİRİYOR
await this.budgetAllocationRepository.save(allocation);          // ← DİSKE YAZIYOR
```

**Tip uyuşmazlığı ölçüldü:**

| Alan | Transformer | Runtime tipi |
|---|---|---|
| `allocation.onInvoiceUtilized` (`budget-allocation.entity.ts:104`) | **`DecimalTransformer` VAR** | `number` |
| `reservation.onInvoiceAmount` (`budget-transaction-log.entity.ts:40`) | **YOK** | `string` |

`number - string` → sayısal coercion → **`-=` doğru**.
`number + string` → **birleştirme** → `+=` bozuk.

**Ölçüldü (node, ampirik):**

```
utilized = 500, amount = "100.00"
500 - "100.00"  → 400          (doğru)
500 + "100.00"  → "500100.00"  (string!)
DB'ye yazılan   → 500100       (olması gereken: 600)
```

Aynı satırda `-=` doğru, `+=` bozuk — **muhtemelen bu yüzden bugüne kadar görünmemiş.**
