## Açıklama — **canlı, kullanıcıya dokunan kusur**

Frontend route kapıları hâlâ **deprecated** `'MANAGER'`/`'FINANCE'` dizelerine göre kurulu.
`hasRole` `ADMIN` dışında **deny-by-default** (`roleUtils.ts:50` → `requiredRoles.includes(userRole)`).

| route | `requiredRole` | dışlanan kanonik rol |
|---|---|---|
| `/plan-approvals` | `['ADMIN','MANAGER','READONLY']` | **`CATEGORY_MANAGER`** |
| `/agreement-approvals` | `['ADMIN','MANAGER','FINANCE','READONLY']` | `CATEGORY_MANAGER` + `FINANCE_MANAGER` |
| `/finance` | `['ADMIN','FINANCE','CATEGORY_MANAGER','READONLY']` | `FINANCE_MANAGER` |
| `/off-invoice/upload` | `['ADMIN','FINANCE']` | `FINANCE_MANAGER` + `PLANNER` |

**Team Lead ölçümü (2026-08-11, `main.users`):**

```
CATEGORY_MANAGER = 3   FINANCE_MANAGER = 2   PLANNER = 2   READONLY = 1   ADMIN = 1
MANAGER = 0            FINANCE = 0        ← kapıların izin verdiği roller BOŞ
```

> **BRD'nin birincil onaycısı (`Approver = Category Manager`, `§7.1`) plan onay ekranına
> giremiyor** — `<Navigate to="/dashboard" replace />`. Backend `@Roles(…CATEGORY_MANAGER…)`
> ile route'u **açıyor**, frontend kapıyı kapatıyor.
>
> Ve `READONLY` — salt-okunur rol — **onay ekranına girebiliyor**.

⚠️ `/off-invoice/upload`'ın `PLANNER`'ı dışlaması `§7.2`'nin `import.invoice` yeteneğiyle de
çelişiyor (*"Typical Roles: **Planner**, Finance"*).

**Hiçbir test bunu tutmuyor:** `grep -rln "plan-approvals\|agreement-approvals"` → yalnız
`Sidebar.tsx` ve `routes/index.tsx`.

**Ölçüm:** `docs/analysis/0056-rbac-ve-rls-tasarim-notu.md §A.4.1`

## Yapılacak

1. Dört route'un rol listesini **kanonik kümeye** hizala. Deprecated etiketleri (`MANAGER`,
   `FINANCE`, `APPROVER`) kapılardan çıkar — ama **K1 kararı** (etiketlerin geleceği) ayrı;
   bu task yalnız **kapıları** düzeltir.
2. **`§7.1`'e göre** doğru kümeyi belirle, backend `@Roles(...)` ile **karşılaştır** —
   iki kopya ayrışmış durumda ve bu ayrışmanın kendisi asıl kusur.
3. **`§7.1`'in tersini de sor:** `READONLY` onay ekranlarında ne arıyor? (Görüntüleme
   meşru olabilir — ama onay **düğmesi** görünüyorsa ayrı bir kusur; **ölç**.)
