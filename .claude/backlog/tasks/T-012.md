## Kapsam (yalnızca threshold config — architect ayırdı; SpendCalc spillover → [[T-017]])
- Budget threshold hardcode: `finance-reporting.getUtilizationStatus` (95/80),
  `budget-allocation.service` (80/95/100), `budget.service.getBudgetStatus` (95/80),
  `on-invoice-validation.service` (100/80) → config-driven.
- Çözüm: `BudgetAlertConfiguration` entity'sine `thresholdPercent` (decimal) ekle + tek
  `BudgetThresholdService` (getThresholds cache'li, satır yoksa 80/95/100 fallback; toStatus; isExceeded).
- Sınır (BRD): <80 GREEN, 80≤x<95 AMBER, x≥95 RED, x≥100 block (hardLimitMode). on-invoice 95-100 AMBER→RED düzelir.
- Terminoloji: `YELLOW` → `AMBER` (tek kanonik `UtilizationStatus`). **Frontend'e sızıyorsa doğrula** (gerekirse frontend follow-up).
- `BudgetAllocation.alertThreshold80/95/100` switch'lerine DOKUNMA (on/off, değer değil).
