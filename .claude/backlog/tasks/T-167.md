## Bulgu ([[T-143]] turu 22 / `docs/analysis/0040`)

`Section_07 §7.5 Data Security & Isolation`:

```
- Every table has `tenant_id` column
- Row-Level Security (RLS) enforced at database level
- No cross-tenant data visibility (even for admins)
```

ve somut politika örneği:

```sql
ALTER TABLE plans ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON plans
  USING (tenant_id = current_setting('app.current_tenant')::UUID);
```

⚠️ Ve uygulama filtresi **yerine değil, EK olarak**: *"Every query **must** filter by
tenant_id — **Required!**"* → **derinlemesine savunma.**

**Ölçüm** (şema-nitelendirilmiş): **0/43 tabloda RLS, 0 politika.** `INV-T-003` VIOLATED.
