## `docs/analysis/0014`'ün F1 fazı — tek yerinde düzeltilebilir kusur

```ts
from: (value?: string | null) => {
  if (value === null || value === undefined) return value;
  const num = Number(value);
  return Number.isNaN(num) ? null : num;   // ← iki kusur, tek satırda
}
```

**Kusur 1 — float dönüşümü.** ADR 0007 F1'de ölçülmüştü, T-090'da **yeniden doğrulandı**: tam
ondalık string IEEE-754'e giriyor. `INV-N-002` bunu yasaklıyor.

**Kusur 2 — sessiz null (YENİ).** Ayrıştırılamayan bir para değeri **"değer yok"a dönüşüyor**.
CLAUDE.md §2.5'in tam tanımı: *"finansal bir yolda çözülemeyen girdi → açık hata fırlat."*

## ⚠️ Spec kusurları KİLİTLİYOR

`decimal.transformer.spec.ts` yeşil (7 test, exit 0) ama `:13` float dönüşünü ve `:17` sessiz
null'ı **sözleşme yapıyor**. Bu oturumda üçüncü kez: test doğru davranışı değil **mevcut**
davranışı sabitliyor.

Düzeltme spec'i de değiştirmeli, ve **neden değiştiğini** yorumda söylemeli.

## ✅ Artık ratchet'e bağlı (F0, backend `ce63344`)

`src/database/` Alan A'ya alındı; bu dosyanın `Number(value)`'ı tabanın **168 bulgusundan
biri**. Yani kusur bir sayıya bağlı: düzeltilince taban düşer, düzeltilmedikçe görünür kalır.
`INV-N-002` için somut takip mekanizması.

## ⚠️ KAPSAM SINIRI — Kusur 2 bağımsız, Kusur 1 DEĞİL

**Kusur 2 tek başına düzeltilebilir:** NaN'da `throw`. Davranış değişikliği var ama dar —
bugün sessizce `null` dönen bir yol gürültülü hâle gelir, ve o yol bugün hiç tetiklenmiyor
olabilir (ölç).

**Kusur 1 tek başına düzeltilemez.** `docs/analysis/0014` ölçtü: `Number()`'ı kaldırmak
`MoneyMinor`'a geçmek demek, o da tanım gereği **her okuyucuyu** değiştirir — 5 entity'nin tüm
tüketicileri. Ve string'e dönmek T-026 regresyonudur (`'500000.00' >= '8187.00'` lexicografik).
`number` kalıp tam olmak imkânsız: 33 kolon `numeric(18,2)`, 2^53 üstü değerler temsil
edilemez.

Yani **"önce transformer'ı düzelt, sonra yay" diye iki aşamalı bir plan yok** — Kusur 1'in
düzeltmesi zaten yayılımın kendisi (F4), ve F4 `D-15`/`D-16`/`D-17` kararlarını bekliyor.
